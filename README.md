# Watermelon Toolbox

A modular toolkit for multimodal quality assessment of watermelons. This project restructures the original `watermelon_eval` codebase into a reusable package.

## Project Layout

```
watermelon_toolbox/
├─ toolbox/
│   ├─ data/
│   ├─ models/
│   ├─ engine/
│   └─ utils/
├─ scripts/
├─ tests/
├─ docs/
└─ README.md
```

The package requires Python 3.9 or higher. See `pyproject.toml` for dependencies.

Development is tracked in the `legacy/` directory for historical scripts.
